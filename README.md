# ODM 项目需求跟踪

## 最新：信息栏抽屉与默认填入（2026-10-26）

项目开发表上方“收起信息栏/展开信息栏”控制采购公司、项目名称、终端客户三列，勾选和编辑保留。浏览器记住上次选择，收起不影响导出内容。

“默认填入设置”可独立启用和修改负责人、品牌、产品线、币种、数量单位、计价说明。所有字段初始为空且关闭，保存在本机数据库。新建报告自动预填，当次可修改/清空；旧记录、原表导入、订单及独立新增规格入口不自动套用。品牌有独立字段，Excel存在品牌时在原18列之后追加品牌列。

AI扫描/API Key仍未实现；后续API可省略默认字段，由本机补齐，减少重复文字。图片识别本身仍消耗token，不保证固定节省比例。最新证据与浏览器授权限制见docs/acceptance/20261026/report-defaults/验收记录.md。

## 架构

- `frontend`：Vue 3 + Vite 用户界面。
- `backend/springboot`：Spring Boot 项目主数据 API，使用 H2 文件数据库保存项目记录。
- `backend/flask`：Flask 统计、Excel/CSV 导入预览与导出服务，通过 HTTP 调用 Spring Boot API。

## 环境

- Node.js 20.19+ 或 22.12+（Vite 8 要求）
- Java 17 或更新版本
- Maven 3.9 或更新版本
- Python 3.10 或更新版本

## 本地启动

### 这台电脑已配置的环境

双击本目录的 `start-app.cmd` 可启动三个服务并打开浏览器；使用完双击 `stop-app.cmd` 关闭服务。启动器使用已配置的 Python，不受 PowerShell 脚本执行策略影响，不需要管理员权限。日志保存在 `logs` 目录。日常运行依赖已配置Java/Python、Flask依赖、后端JAR和前端dist；前端使用内置静态服务，不启动Vite。源码压缩包不包含运行环境、依赖和构建产物。

数据库只读问题已通过正常 Windows 进程运行方式解决；实际页面新增、整套应用停止再启动、重启后编辑保存和 CSV 导出已通过验证。另有隔离数据库上的 25 项检查通过。启动器会检查数据库是否可写，详细结果见 `功能验证记录.md`。

运行工具安装在工作区的 `.tools` 目录，Flask 依赖安装在 `backend/flask/.venv`。这是本项目使用的独立环境；普通终端需要先加载 `environment.ps1` 才能找到这些命令。

开发时可使用下面的 PowerShell 入口（需要本机允许运行本地 PowerShell 脚本）。日常使用请双击 `start-app.cmd`：

```powershell
# 终端 1
./run.ps1 springboot

# 终端 2
./run.ps1 flask

# 终端 3
./run.ps1 frontend
```

然后打开 `http://127.0.0.1:5173`。每个服务可以在对应终端按 Ctrl+C 停止。

只加载命令环境时使用：

```powershell
. ./environment.ps1
node --version
npm.cmd --version
java -version
mvn.cmd --version
python --version
```

`environment.ps1` 使用当前工作区的相对目录和本机 Python 虚拟环境，不适用于把源码单独复制到另一台电脑的情况。前端依赖版本记录在 `frontend/package-lock.json`，Python 依赖版本记录在 `backend/flask/requirements-lock.txt`。

### 其他电脑手动配置

依次在三个终端中启动服务。

### 1. Spring Boot 主数据服务

```powershell
cd backend/springboot
mvn spring-boot:run
```

服务地址：`http://localhost:8080`

### 2. Flask 统计与 CSV 服务

```powershell
cd backend/flask
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

服务地址：`http://localhost:5000`

### 3. Vue 3 前端

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开 Vite 打印出的地址，通常为 `http://localhost:5173`。

前端直接通过 Spring Boot 进行项目增删改查，通过 Flask 读取汇总并处理 CSV 导入导出。Spring Boot 的 H2 数据文件保存在 `backend/springboot/data/`。

## 表格导入（2026-10-24 更新）

点击“导入项目数据”，选择 CSV、XLS 或 XLSX。支持原九字段项目清单和十八列项目开发报告。先检查预览，补填缺失的项目名称，再勾选并确认当前工作表。完全相同记录跳过，其他变化新增，不自动覆盖旧记录。文件夹请先打开，再选择里面的表格。

空模板会显示“没有项目记录”，不会写入空项目。Word/PDF/图片识别、AI API 接入仍属于后续开发。

原九字段 CSV 表头：终端客户、ODM集成商、模组厂、项目名称、应用、目前阶段、测试阶段需求数量、项目预计总需求量、预计MP日期。

“导出项目数据”保留旧项目字段及原报告资料的CSV输出。开发分支的“导出项目表（Excel）”现输出18业务列的XLSX工作簿，包含开发、成交、EOL和重点项目四张表；旧版报告CSV接口仍保留兼容，但不再作为页面主导出按钮。完整备份仍应停机保存数据库及客户文件夹。

详细使用步骤、字段映射与限制见 `docs/导入功能使用说明.md`；最新进度和验收记录见 `docs/工作进度_2026-10-24.md`。

## 公司工作台与本周更新（2026-10-26）

左侧“全部客户”按实际采购公司集中查看项目与变更记录。新建客户后自动建立桌面客户文件夹，失败可在客户页面重试。公司与终端客户分别记录；原有项目先放在“未归属项目”，可勾选后统一归属到已建客户。公司改名不改变客户编号，也不移动已有文件夹。

“本周更新”包含客户和项目的新增、修改，显示每次实际变化和所属公司，支持公司筛选、分页和查看原记录。按北京时间周一00:00至下周一00:00统计；旧项目不会被自动算成本周新增，打开后原样保存、导出、重复导入跳过不产生更新。

导入预览可选择本次所选记录的采购公司。原表客户名称仅作候选提示，不自动匹配或建客户；多公司报告可分批勾选导入。项目导出增加可选“实际客户”列，重导入时需人工确认归属，不直接恢复其他数据库的客户编号。项目CSV不是客户主档、所有变更历史或桌面文件的完整备份。

客户主档现已扩展备案字段和长期交易条件，项目支持多型号规格与业务跟进，开发分支已增加重点项目及订单登记。交货、收款、Word自动生成、截图识别与AI服务仍按后续计划建设。最新接续开发说明见 `docs/开发进度与后续计划.md`。升级前请停止应用并备份整个 `backend/springboot/data` 目录；不要把业务数据库或客户文件夹上传到公开仓库。

## 客户备案与长期交易条件（开发分支，2026-10-26）

新建或编辑客户时，可切换基本资料、建档信息、联系与需求、长期交易条件、对账与开票、资料状态与客户分类、人工经办与审核分组，统一保存所有分组的修改。公司全称仍是唯一必填项，未知的信息可先留空。公司页可展开查看保存的资料，修改后的字段差异进入“本周更新”。

收款条件支持预付款、货到付款、月结30至180天及其他约定。对账与开票日期按原约定填写规则；信用额度保留金额、币种和单位。评级、审批和核准均由人工填写，不自动默认通过。订单确认时自动保存客户交易条件快照。

客户备案首次实施时完成构建、代码审查和布局查看；后续检查已补充隔离数据库回归，最新证据见 `docs/acceptance/20261026/sales-orders/验收记录.md`。接口合并规则及实施范围见 `docs/implementation/20261026/客户备案与长期条件实现记录.md`。当前已发布的 `v1.1.0` 不包含此开发分支的新功能。

## 项目型号规格与业务跟进（开发分支，2026-10-26）

项目列表每一行的“规格与跟进”可打开项目业务详情。同一项目下保存多条材料型号和成品规格，每条明细独立维护当前报价、币种、数量单位、计价含税说明、需求预测、量产预估和业务阶段。项目原有EVT/DVT/PVT仍是辅助测试阶段，不会被明细业务状态覆盖。量产预估允许“2027年第一季度”等原精度文本。

切到“跟进与变更”，可为项目整体或具体明细追加跟进，填写发生日期、内容、资料来源、下一步及下次跟进日期。新增跟进时可明确选择同步修改该明细阶段；系统保留修改前后阶段。直接修改报价等字段也会在此保留前后值，不覆盖旧记录。截图来源目前只保存说明，尚未关联截图附件。

明细采用归档/恢复，不提供物理删除；带有任何明细或跟进的项目会阻止单项及整批删除。新增明细与项目删除使用同一项目行锁，避免并发操作留下孤儿记录。原报告不自动拆分合并，现有项目CSV暂不包含新增明细和跟进，完整保存请在停止应用后备份本地数据库。

具体接口、实现范围及最初页面记录见 `docs/implementation/20261026/project-business/实现记录.md`。后续补充了旧功能回归，最新结果见订单验收记录。

## 重点项目与客户订单（开发分支，2026-10-26）

项目行可单独标记重点，左侧“重点项目”集中查看。标记与技术、业务阶段独立，实际变化进入本周更新。

左侧“客户订单”查看全部订单，也可进入公司页查看该客户的订单和累计金额。建单前先建立客户，将项目归属该客户，并在“规格与跟进”中添加型号规格。

新订单选择样品单或量产单、日期、币种及型号规格，填写实际数量、数量单位、含税成交单价和订单依据。当前一单支持同一项目的多项型号规格。项目报价仅供参考，不自动作为成交价。复购继续新建订单。

点击“预览并核对”，检查每行、总额和客户条款，再“确认保存订单”。金额按每行数量乘含税单价、四舍五入保留2位后相加；每笔订单有独立总额，客户按币种分别累计，不进行汇率换算。累计金额不表示已收款。

订单保存下单时的客户名称、长期交易/对账/开票条件及项目型号规格快照；后续改档案不追溯修改旧订单。预览后资料发生变化会要求重新核对；重复提交同一笔请求不会重复建单。确认后的订单本期只读，尚无编辑、作废或删除入口，保存前请核对。

“导出订单数据”导出当前客户范围的全部订单明细CSV，可用Excel打开。订单总额只出现在该订单第一行，行金额逐行保留，避免总额重复相加。项目CSV与订单CSV均不是客户档案、条款、全部历史和附件的完整备份；完整保存仍应停机备份数据库，并另外备份客户文件夹。

本期没有实际交货或收款台账，也不会因保存量产单自动修改项目阶段。订单接口、金额与幂等校验、重启保留、旧功能回归及合成数据页面结果见 `docs/acceptance/20261026/sales-orders/验收记录.md`。

## 原报告格式主表与稳定启动（2026-10-26）

主表按原报告18个业务字段展示，每个型号规格一行；无明细的旧项目保留原报告行，不自动合并。采购客户公司、项目名称、终端客户继续固定。每行勾选框下方的“编辑”集中修改整行，横向滚动后仍可点击。“查看金额列 →”直接定位单价、预估年用量和预估年营业额；实际订单及客户累计金额在“客户订单”。分类开发/成交/EOL由人工选择，重点单独标记。明细全部归档时保留恢复入口，不展示已归档报价。

“导出项目表（Excel）”下载所有客户的当前报告行，含开发、成交、EOL、重点项目四张表及原顺序18列，不随列表筛选缩小。重点表是重复展示视图，不能把四表营业额再次合计。输出新XLSX，不覆盖原XLS，不承诺复刻所有公式和打印版式。它不包含完整跟进、实际订单、客户主档和附件。

桌面原快捷方式继续可用。启动器将完整构建复制到logs/runtime独立快照，构建不会改写运行中的文件；检查三个服务就绪后打开页面。重复启动复用正常服务，部分失败时恢复自有服务。构建损坏或候选版本启动失败时尝试一次上次健康版本并保留失败日志。缓存损坏从完整构建重新复制。这是启动时恢复，不是持续后台监控。

- start-app.cmd：启动或恢复。
- check-app.cmd：检查状态。
- repair-app.cmd：重启自有服务。
- stop-app.cmd：停止，保留数据。

未知端口占用或进程身份不符时保留未知进程并提示错误。不要在运行中删除logs/runtime或移动数据库。数据库仍在backend/springboot/data，运行快照不含数据库。开发更新先构建再重启，数据库结构升级前仍需停机备份；运行快照回退不等于数据库回退。最新验收见docs/acceptance/20261026/report-ledger/验收记录.md。

# Excel / CSV 导入完善计划

日期：2026-10-24。用户授权优先支持项目开发报告，随后授权自行处理；已取消关机。

## 方案

沿用 Vue 3、Flask、Spring Boot。选择文件后先解析预览，再由用户确认写入。支持 CSV、XLS、XLSX；文件夹需打开后选择表格。Word、图片识别属于后续 AI 计划。

原九字段保持兼容。开发报告的18列以原始资料保存到每条记录的 reportData，同时映射确定的项目名、终端、应用、精确量产日期。客户不猜成 ODM，年用量不当成项目总量，交易状态不当成验证阶段。原18列可查看并另行导出。

项目报告模板文件当前只有表头，需显示空模板提示；有数据的参考文件仅用于独立环境验收。空项目名及“/”待手动补充；季度不转换成某一天。一次选择一个工作表导入，重点页不自动合并。完全相同记录跳过；其他变化新增，不覆盖原记录。

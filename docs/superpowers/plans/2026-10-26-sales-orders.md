# 订单登记与客户累计金额

## Goal

阶段C订单第一部分：样品、量产及复购独立保存，每单多项型号规格，按含税价格计算订单金额并按客户及币种汇总，订单可核对及导出。

## Architecture / Tech Stack

继续Vue3、Spring Boot/JPA/H2及现有海洋主题。新增订单、明细与客户条款快照表。新订单先预览、再显式确认保存；服务端精确计算、校验归属和保存完整快照，不覆盖旧订单。

## Spec

PRD v0.3 BR-08至12、FR-O01至06。用户在2026-10-26明确：含税价格；需要每笔订单及客户累计金额。沿用已说明的逐行四舍五入2位再合计方式。

## Global Constraints / Rulings

- 基线6909f4c，现有分支codex/sales-orders，复用已安装环境。用户先前要求检查旧功能并已授权测试，本轮继续保留回归。
- 数量、单价最多13位整数6位小数；行金额HALF_UP到2位，总额合计已舍入行金额。JSON金额为字符串，前端不做浮点金额计算。单笔订单明确一个币种，客户按币种分别累计，不转换汇率。
- 必须选已建客户、用途、日期、币种及订单依据；至少一项未归档型号规格。客户订单号未知可空，内部编号由系统生成；项目必须属于该客户。
- 本期一张订单只允许同一项目的多项明细，避免把尚未确认的跨项目业务当作已确认。存储行保留项目ID兼容未来扩展。
- 当前报价仅供查看，不能自动当作成交价格。数量、单位及成交价需核对；同规格复购新建订单，历史不覆盖。
- 保存客户名称、交易条款、项目名/型号/规格、实际数量/单价和金额的快照，客户或项目后续修改不改变旧订单。
- 预览不写入，确认时重新核对归属、快照及金额，预览后资料变化返回409要求重新预览。重复提交同一请求键返回原订单，改变内容复用键则拒绝。同客户相同非空客户订单号提示重复。
- 已确认订单暂不提供覆盖编辑、删除或作废；取消、退款口径待后续确认。此次不实现交货及收款台账，不以成交自动判定已收款，也不自动将明细改为量产。
- 导出当前客户或全部订单明细CSV，带UTF-8 BOM，防止文本公式执行；导出订单快照不包含API密钥或数据库路径。
- 测试、演示只用临时库与合成资料；升级正式应用前离线备份。发布GitHub不包含在本轮。

## Interfaces / Files

- Spring: SalesOrder、SalesOrderLine、SalesOrderRepository、SalesOrderService、SalesOrderController；CustomerRepository及WorkspaceService共用客户行锁；ProjectDetailRepository查询所属项目ID。
- API: POST /api/orders/preview、POST /api/orders、GET /api/orders、GET /api/orders/{id}、GET /api/orders/export；列表返回按币种汇总。
- Vue: OrdersWorkspace（列表/汇总）、SalesOrderForm（录入/预览/确认）、SalesOrderSummary（只读快照）；api.js和App.vue接入全局/公司订单入口。
- Tests: backend/tests/verify_sales_orders.py，复用系统分配端口的隔离服务。

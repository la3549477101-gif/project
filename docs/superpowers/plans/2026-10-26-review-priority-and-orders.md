# 既有功能回归与重点项目

## Goal

检查客户资料及项目型号规格/跟进，修复发现的问题；继续 PRD BR-13 已确认的重点项目标记及独立查看。订单金额开发等用户确认含税口径后衔接。

## Architecture / Tech Stack

继续 Vue3、Spring Boot/JPA/H2 和 Flask；复用现有项目、导航及审计。新增隔离 H2 HTTP 回归检查，不在真实数据库添加测试记录。

## Spec

PRD v0.3 的 BR-13、FR-P09、FR-C02、FR-F02和数据保护要求；用户本轮明确要求继续开发并检查之前功能。

## Global Constraints / Decisions

- 基线 daccf3c，分支 codex/orders-and-review。
- 先运行现有回归，再以真实 HTTP 和临时 H2 覆盖新客户资料、金额、跟进、事务回滚、并发和重启。
- 修复先写失败用例再改代码。已复现客户审核日期允许0000年；应用日期限制1至9999年。
- 重点是项目的独立布尔标记，不复制项目、明细和需求。旧记录默认不标重点，不生成伪修改时间。
- 独立标记接口避免旧客户端保存项目时无意清除标记；标记实际改变时才进入本周更新。
- 重点列表仍按原项目ID去重，搜索与测试阶段筛选继续可用，原全部项目数不因标记增加。
- 原计划订单金额的含税口径尚未确定，已一次询问一个问题；依赖此答案的金额计算暂不实施，不猜测税率、币种或舍入规则。

## Review Focus

回归预期独立、临时服务可靠清理、无正式数据污染；标记与旧编辑/导入兼容、 no-op审计及项目数量不重复。

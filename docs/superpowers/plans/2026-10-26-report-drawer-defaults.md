# Report drawer and defaults Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline; one fresh review at completion.

**Goal:** 可收起报告三列固定区，为新报告提供可修改、可停用的默认填入，后续API可复用。

**Architecture:** Vue筛选固定列并重新计算表格总宽；浏览器仅记住展开状态。Spring新增带版本的单行设置实体和GET/PUT接口，在POST报告时补省略字段。Vue先读设置再打开新建表单，集中设置弹窗写后端。

**Tech Stack:** Vue3、现有Spring/JPA/H2、Node自带检查、现有临时H2验证工具。

**Spec:** docs/superpowers/specs/2026-10-26-report-drawer-defaults-design.md

## Global Constraints

- 复用codex/report-ledger当前安装目录，正式数据不用于测试写入；升级停机备份后启动。
- 默认值仅POST省略字段生效，显式空白和PUT旧记录优先，不回填历史。
- 全部设置初始关闭，校验文本长度/未知字段/版本冲突；沿用海洋视觉。
- 收起不影响18列导出和批量项目选择；勾选编辑始终固定。

## Review Focus

- 异步加载覆盖用户刚输入内容：先加载设置再初始化新建表单。
- 编辑旧记录或主动清空被默认填入覆盖：仅POST缺失键/null元字段补齐，空串保留。
- 两窗口修改设置：版本冲突409；首次保存并发也不可静默覆盖。
- 浏览器存储不可用：抽屉仍能本次使用，不阻止数据读写。
- 收起后的表格宽度、金额定位和编辑行对应关系：合成界面检查，导出18列不变。

# 项目批量删除设计

## 意图与目标

在项目总览中勾选多条项目后一次删除，减少逐条删除的操作。表头勾选只选择当前显示的项目；筛选条件变化时清空选择；执行前明确显示数量并再次确认。

## 不做的范围

本次不提供回收站、撤销或软删除，也不改变现有单条删除操作。删除仍是永久操作。

## 方案

- 逐条调用现有删除接口：改动较少，但中途失败时可能只删掉一部分。
- 新增后端批量删除接口：后端一次处理所选 ID，界面操作一致，较容易保证批量操作完整性。**采用此方案。**
- 软删除/回收站：可撤销，但需要改变数据模型和恢复流程，超出这次“小工具”改动范围。

## 交互与约束

项目表格每行增加复选框；表头复选框选择当前筛选结果。选中后显示“已选择 N 个项目”“删除已选项目”和“取消选择”。确认框列出数量及最多前三个项目名，并说明删除后无法恢复。后端拒绝空 ID 列表、无效 ID 和超过 5000 条的请求，去重后返回实际删除数量。页面继续使用海洋主题，单条删除保留。

# 界面英文缩写中文注释设计

## 意图

让不熟悉英文缩写的使用者能直接理解项目跟踪界面中的 ODM、EVT/DVT/PVT、MP 和 CSV。

## 目标与范围

- 在界面标签、选项和操作按钮中，将常见英文缩写与简短中文解释并列显示。
- 包括 ODM（原始设计制造商）、EVT（工程验证测试）、DVT（设计验证测试）、PVT（生产验证测试）、MP（量产）和 CSV（逗号分隔值）。
- 仅调整 Vue 前端文案；数据库字段、API 值、CSV 表头和导入导出格式不变。

## 方案比较

- 直接在缩写旁显示括号解释：随时可见，适合触屏和初次使用者。**采用此方案。**
- 通过鼠标悬停显示解释：界面更简洁，但触屏和移动端不易发现。

## 约束与非目标

- 保留 EVT、DVT、PVT、MP、ODM、CSV 原有标识，避免改变阶段值和文件格式。
- 本次不改布局、字段结构、后端行为或数据迁移。

## 实现范围

- 更新 Vue 页面中标题、ODM 集成商字段、阶段统计与筛选/编辑选项、MP 日期字段以及 CSV 导入/导出按钮。
- 修改后只做源码差异检查；本次不新增或运行测试。

# 表格导入使用说明

更新：2026-10-24。

## 操作步骤

1. 通过桌面原快捷方式打开应用，点击“导入项目数据”。
2. 选择 `.csv`、`.xls` 或 `.xlsx` 文件。文件夹需要先打开，再选择里面的表格；Word、PDF、截图暂不支持。
3. 选择工作表，查看解析出的记录与逐行提示。一次确认一个工作表，其他表可再次选择同一文件导入。
4. 空项目名称、`/` 或 `／` 需要补填；超长名称可在预览中缩短。量产日期允许空白，不确定时留空。
5. 勾选要保存的有效记录。季度/月度时间会保留原文，不自动猜成某一天。其他不能在此修改的字段错误，需要更正源表后重新选择。
6. 点击“确认导入 N 条”。取消或关闭预览不会保存记录。
7. 成功后会显示新增数和完全重复跳过数，刷新后仍可查看。

预览每页25行，可切换“仅显示待处理记录”。完全相同的内容跳过；改变过的内容新增，不自动更新或覆盖旧项目。相同项目的不同型号、规格分别保留。重点项目工作表可能与开发页重叠，需要人工核对选择。

## 支持的表头

- 原九列清单：终端客户、ODM集成商、模组厂、项目名称、应用、目前阶段、测试阶段需求数量、项目预计总需求量、预计MP日期。
- 十八列开发报告：负责人、日期、产品线、案子状况、客户、终端客户、项目名称、应用、材料型号、成品规格、单价、预估年用量、预估年营业额、项目状态、预估量产时间、竞争对手、竞争对手单价、备注。
- 识别“单价（含税）元”等实际表头，保留原表头及价格口径；识别表头中的空白和换行。
- 表头前可有说明行；合并单元格的空白不会自动沿用上一行的值。
- 项目开发报告当前四张表只有表头，没有业务记录，识别后会提示空模板。需要填入实际记录后才能导入。

## 原字段如何保留

开发报告中确定的项目名、终端客户、应用和精确量产日期映射到现有项目字段；客户不猜成ODM，年用量不当成项目总量，交易状态不转换成 EVT/DVT/PVT。

每条记录同时保存原十八列和文件、工作表、原表行号。在项目“编辑”中的“原开发报告”可展开查看。这些是原始资料，不会因修改现有项目名称而改写；导出报告的项目名称使用当前已确认值。型号、规格、价格和跟进备注的完整结构化编辑属于后续CRM版本。

普通九列清单出现未知附加列时会明确提示这些列不会导入，请先核对。十八列报告的附加列会保存在原始资料中。

## 导出与再次导入

- “导出项目数据”：备份全部项目。存在原报告资料时追加“开发报告原始资料”列，再次通过预览导入可保留资料。旧九列导出仍兼容。
- “导出开发报告”：只包含已有原报告资料的记录，输出十八业务列及原单价表头、备份JSON、来源信息。普通手动新建项目不会被伪造为原报告记录。该文件是Excel可打开的CSV，未复刻原XLS的颜色、合并单元格和分页版式。
- 报告导出统一用“单价”展示数值，紧随附加的“原单价表头”说明原口径，原始JSON继续保存完整原表内容。没有明确税标记的“单价”不被认定为含税。
- 修改过的记录重新导入会新增；当前功能不做业务主键匹配后的自动更新。

## 文件限制

单文件最多5 MB、20张工作表、100列、合计5000业务行；XLSX解压后最多20 MB。确认的展开数据最多64 MB。CSV支持UTF-8/BOM、GB18030。数量只接受空白或安全范围内的非负整数，九字段阶段只接受空白/EVT/DVT/PVT，精确日期使用YYYY-MM-DD。

不执行工作簿中的宏或公式。XLSX公式保留文本并提示核对；XLS读取已缓存的公式结果。原项目名为XLSX公式时需要人工填写确认的名称。加密或损坏文件需先在本机Excel中解除保护/重新保存。

## 本次发现并修复

- 原文件选择器和接口只接受固定CSV，不支持Excel。
- 超长名称缩短后原错误未清除；现按UTF-16长度即时校验并恢复可选。
- XLSX展开数据确认可能超过上传5MB限制；文件保持5MB、确认数据上限64MB。
- 含税表头在报告导出后形成重复规范列；改为单套18列+原单价表头+原JSON，重导不会嵌套。
- 普通项目不伪造原始开发报告来源；完整备份使用全部项目CSV。
- 异常原报告JSON导出提供可读错误，不返回500。

## 边界

项目报告模板文件当前四张表均只有表头，空模板不会生成项目。支持表头固定为已适配的九列/十八列；不是任意文档通用识别。文件夹需打开后选择表格，Word/PDF/截图与AI API-key尚属后续。内容修改后重新导入会新增，不自动更新。导出为CSV，未复刻原XLS格式。原报告原始资料可查看，型号/价格/跟进的完整结构化编辑属于下一阶段。

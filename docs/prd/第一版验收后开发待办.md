## 4 截图资料与AI录入

先支持用户将截图发送给当前对话，由助手识别、自检并通过应用录入，沿用统一的草稿与确认流程。

应用内AI接口后续任务明确包括：

- 配置模型服务、地址、支持识图的模型及API Key。
- API Key由后端安全保存，不放在前端源码、导出文件或日志中。
- 应用内上传或粘贴聊天截图，多图资料的来源与顺序核对。
- 调用视觉模型提取客户、项目、型号规格、订单及跟进信息。
- 结构化草稿、字段来源、空缺和冲突提示；不能只凭下单意向生成真实订单。
- 不确定项留空并询问用户；通过确认后写入，支持匹配现有记录和提示重复。
- 处理服务未配置、密钥无效、超时和额度不足等情况，手动录入始终可用。
- 接入前确定模型服务费用、图片保留方式和资料外发范围。

本清单不要求用户现在提供API Key。具体接入服务、细节和验收标准在该阶段开始前逐项确定。

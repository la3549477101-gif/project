# 前端视觉约定

用户于2026-10-24提供海洋摄影风格参考，并要求后续页面继续采用同一风格。

- 后续客户档案、项目、订单、跟进、导入识别等页面统一沿用海洋主题。
- 先读 `../docs/页面视觉规范.md`，复用 `src/ocean-theme.css` 的 `--ocean-*` 变量和现有组件样式。
- 用户于2026-10-26补充水下光束参考：水下蓝背景、右上方青蓝透光、浅色文字、细边框和半透明蓝色面板；表格和表单优先确保文字、状态和输入框清楚可读。
- 项目表左侧勾选框、采购客户公司、项目名称、终端客户一起固定；固定区紧凑以保留右侧数据空间，单元格使用同色不透明底，防止横向滚动文字重叠。
- 业务内容以中文为主，英文缩写提供中文解释；操作按钮按动作与对象命名。
- 用户可用信息栏抽屉一起收起/展开采购公司、项目名称、终端三列；收起后勾选/编辑仍固定并保留展开入口。默认设置不覆盖旧记录或用户本次清空的内容。
- 当前本地背景资源为 `public/images/underwater-workspace-v2.png`，旧版海面资源保留；不替换成依赖外部服务的图片或字体。
- 桌面布局保留有效数据密度，小屏幕按钮可换行、表格在自身容器滚动；不要用超高装饰区推走业务内容。
- 新增主题规则应进入共享主题文件，避免每个页面另写一套不一致的配色。
